# KARTSEEK Admin Platform — Second-Round Audit (Super Admin + Regional Admin)

Date: 2026-09-12 · Branch inspected: `feat/admin-platform-upgrade` at `e0c7832` · Editor: consolidation of eight parallel investigations

## 0. Method and scope

Eight investigators worked the branch in parallel and read-only: **A** Docker and environment configuration (static read of `docker-compose.yml`, `infra/docker/*`, `infra/k8s/*`, `infra/nginx/*` and every `.env`, plus a read-only `docker ps`), **B** database connectivity (static read of every `forRoot`/`registerPostgres` call site, then **live** probes against all nine Postgres instances, MongoDB, Redis and Elasticsearch using the credentials each application actually resolves, every write probe wrapped in `BEGIN … ROLLBACK` and re-counted afterwards), **C** cache and regional isolation (static grep of every Redis key template under `apps/api/**` and `modules/*/backend/**` plus a **live** `SCAN` of the dev Redis at `DBSIZE`=297), **D** console inventory (static census of all 250 admin pages joined to client method → gateway route → RPC command → backend `@MessagePattern`, reproducible with `node apps/api/scripts/verification/admin-console-census.mjs --json .superpowers/sdd/2026-09-12-admin-platform-review/inspect-D-console-inventory.json --md <anywhere>/admin-console-census.md` from the repo root on Node ≥ 20 with no dependencies), **E** regional function consistency and regional access security (static trace gateway handler → RPC → `@MessagePattern` → query for every admin-reachable route, with scratchpad census scripts), **F** console API connection and error handling (static), **G** WebSocket and Kafka/event wiring (static, plus **live** read-only `kafka-topics.sh` / `kafka-consumer-groups.sh` against `kartseek-kafka`), and **H** security (static, plus existing specs re-run: 4 guard/regression files, 32 tests passed; 5 controller/service files, 148 tests passed). No investigator started, stopped, installed or mutated anything; the application fleet was **not** running during B's and A's probes, so their live results describe configuration and schema reality, not live traffic. Everything the Plans A + B completion report (`docs/superpowers/plans/2026-09-12-admin-platform-completion-report.md`) proves fixed, and every row of the 2026-09-11 registers carrying a FIXED note, is excluded from this document; register rows without a FIXED note are carried over below with their original id. Where two investigators contradicted each other the contradiction is stated and the stricter reading taken; where an investigator's own severity scale differs from this document's priority definitions the finding is mapped up, never down.

### (c) The single platform rule set E proposes

**Country → Region → Module → Entity, as code.** Four links, one implementation each, no exception without a `@GlobalEntity('<reason>')` or a `MARKET_EXEMPT` entry a spec reads.

```
1. CLAIM     users.region_code (ISO-2, NULL = global) + users.region_locked
             → AuthController.issueTokens → JWT { regionCode, regionLocked }
             → JwtStrategy.validate → req.user          (correct today — unchanged)

2. GATEWAY   every admin-reachable handler, in EVERY controller:
               const { scope, market } = this.scopeOf(req, requested, what);
             - `market` is the filter to send (undefined = every market)
             - `scope`  is set only when the caller is locked; it is the proof
             - a locked caller naming another market is refused HERE and logged
             Writes to a global entity call refuseLockedAdmin(req, what) instead.
             Move `scopeOf` out of the eight copies into one shared base class or a
             `@MarketScoped()` param decorator so it cannot drift.

3. BACKEND   every @MessagePattern that takes `scope`:
             - list                  → marketPredicate(scope, requested) in the query
             - read/write of one row → load it, then
                 assertInMarket(row.<marketColumn>, scope, '<what>', this.logger)
             - no column and no owner to join to →
                 refuseUnattributable(scope, '<what>', this.logger)
             All four from @app/common. No private re-implementations.

4. COLUMN    ONE name, ONE shape, everywhere: `region_code` varchar(2), ISO-2,
             NULL = global, plus `is_global boolean` where "runs everywhere" must be
             distinguishable from "not yet attributed". Entities with no column of
             their own attribute through exactly one documented owner join, named in
             the entity docstring.
```

### (f) The proposed single error contract

**One `apiCall`.** Retire `api-fetch.ts`, `api-client.ts`, `api/admin-core.ts`'s `apiCall`, `api/admin-marketplace.ts`'s `apiCall` and the six copy-pasted `apiCall`s. ### (e) Test cases a cache-isolation spec must assert

For each module: **write as market A, read as market B → must miss or be refused, never return A's cached payload.**

1. **Marketplace home feed** — POST a banner scoped `regions:['QA']`, then `GET /marketplace/home` with `X-Region-Code: AE` immediately; the QA banner must not appear and the response must not come from a stale `marketplace:home:AE`.
2. **Marketplace product listing** — approve a QA seller's product; `GET /marketplace/products?country=AE` within the TTL must not include it, and `?country=QA` must include it within one TTL window.
3. **Grocery categories** — `stockedOnly=true` for QA then AE must differ when the stocked sets differ, and a category rename must invalidate **both** `stocked:QA` and `stocked:AE`, not just the unscoped key.
4. **Taxi fare estimate** — request an estimate with pickup coordinates inside Qatar and **no `zoneId`**; assert the rate card used is `taxi:rates:QA`, not `taxi:rates:IN`/`DEFAULT_ZONE`. Repeat with Indian coordinates and confirm QA's just-cached card is never returned. **The highest-value new test in the suite.**
5. **Taxi surge/demand** — simulate demand in one H3 zone and assert another country's surge is unaffected; assert the `DEFAULT_ZONE` literal path is removed or provably unreachable.
6. **Search** — index one `countryCode:'IN'` and one `'QA'` document, call `search()` with `filters.country:'QA'` while forcing `esAvailable = false`, and assert only the QA document returns.
7. **Admin revenue report** — `GET /admin/reports/revenue?country=QA` as a QA-locked admin must return QA-only figures or the documented `NotImplementedException`, never the global counter total.
8. **Cross-module smoke** — for every `${region}`-templated key in §9(a), assert a write under A and a read under B within one TTL window never observe each other.
